Streamir

A richer voice, generated locally.

Install Qwen once, then connect it to the Streamir viewer. Speech generation uses your computer; no translation API key is needed by this extension.

1. Install the model and helper

Use the repository’s setup guide to download Qwen3-TTS and create a local configuration. NVIDIA GPUs use CUDA. Apple Silicon uses MLX and Metal. CPU mode is available but can be much slower.

The streamer’s voice arrives from Streamir as an encrypted pack when you enable it on the page. It is not stored on your computer.

The model stays loaded while you watch. Closing or disconnecting the viewer releases it.

This development build requires a local Python environment and Node.js. The download can be several gigabytes.

3. Connect your viewer

Open the Streamir viewer page, click this extension, and choose Connect this viewer. Then enable local voice on the page.

Only the connected tab can request speech. The page handles captions, chat, playback timing and volume. Generation may add delay; the viewer should show when speech falls behind.

The new viewer connection is still being coordinated. Local voice is not yet connected to the live server feed.
